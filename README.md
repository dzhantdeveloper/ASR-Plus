# ASR+ — Auto Steam Rental Plugin for Cardinal

**Версия:** 1.2.0
**Платформа:** [Cardinal (FunPay)](https://github.com/sidor0912/FunPayCardinal)

Расширенный плагин для автоматической аренды Steam-аккаунтов через FunPay.
Поддерживает как классическую почасовую аренду (1 час = 1 единица товара), так и лоты с фиксированным временем.

---

## ✨ Возможности

### Выдача и аренда
- **Авто-выдача** — при поступлении заказа аккаунт выдаётся покупателю автоматически
- **Почасовые лоты (`hourly`)** — количество купленных единиц = количество часов аренды
- 🆕 **Фиксированные лоты (`fixed`)** *(1.2.0)* — время аренды задаётся один раз в настройках лота и не зависит от количества в заказе
- **Steam Guard** — покупатель получает актуальный код по команде `!код` / `!code`
- **Таймер аренды** — покупатель видит остаток времени командой `!статус` / `!время`
- 🆕 **Уведомление о скором окончании аренды** *(1.2.0)* — покупателю автоматически приходит предупреждение незадолго до истечения срока
- **Автосмена пароля** — после завершения аренды пароль Steam меняется автоматически
- 🆕 **Повторные попытки смены пароля** *(1.2.0)* — при временном сбое Steam плагин повторяет попытку вместо разовой ошибки
- **Авто-возврат** — при ошибке выдачи заказ автоматически возвращается покупателю
- 🆕 **Проверка активных аренд покупателя** *(1.2.0)* — исключает случайную повторную/дублирующую выдачу аккаунта одному и тому же покупателю

### Продление аренды
- **Продление аренды** прямо в чате командой `!продлить` / `!extend`
- **Лот-продление** — отдельный лот, привязанный к основному, специально под продление
- 🆕 **Несколько вариантов продления с разным временем** *(1.2.0)* — для фикс-лотов можно настроить сразу несколько лотов-продлений (например, +5ч / +10ч / +24ч), покупатель сам выбирает вариант в чате
- 🆕 **Точное определение купленного лота-продления** *(1.2.0)* — продление срабатывает только если оплата реально пришла с настроенного лота-продления, а не с любого совпадающего по тегу лота (устранена ложная привязка продления к чужому заказу)
- **Продление по тегам** — общий лот-продление можно задать сразу для всех лотов с одинаковым тегом
- **Авто-отключение лота-продления** — лот-продление автоматически выключается через заданное время, если им не воспользовались, и включается заново по требованию

### Распознавание лотов и заказов
- 🆕 **Авто ID (match tag)** *(1.2.0)* — плагин автоматически генерирует уникальный служебный тег и дописывает его в описание лота на FunPay, что позволяет безошибочно распознавать заказы даже при похожих/дублирующихся лотах
- **Привязка к тегу** — каждый лот привязывается к тегу, определяющему пул аккаунтов для выдачи
- **Fallback-распознавание по `#тегу`** в подробном описании лота, если тег не задан в настройках
- 🆕 **Улучшенный парсинг описания лота** *(1.2.0)* — более надёжное извлечение тега и служебных меток из HTML-описания
- **Фильтр «наш раздел»** — защита от случайной выдачи по чужому, но похожему лоту в той же подкатегории

### Управление лотами
- **Автовкл/выкл лотов** в зависимости от наличия свободных аккаунтов по тегу
- **Ручное управление** лотами и вариантами продления через Telegram-бота

### Аккаунты и покупатели
- **Bulk-загрузка** аккаунтов через `.mafile`
- **Чёрный список** — блокировка нежелательных покупателей
- **Бонусы за отзыв** — настраиваемые бонусные часы за оставленный отзыв
- **Ручная выдача** — ручной старт аренды из Telegram-бота (в обход авто-логики)
- **Резервное копирование паролей** — история смен пароля с возможностью восстановления

### Статистика и уведомления
- **Статистика** — выручка, топ тегов, история заказов, экспорт в `.txt`
- 🆕 **Единая классификация ошибок** *(1.2.0)* — более понятные и структурированные сообщения об ошибках в логах и в уведомлениях Telegram
- **Уведомления в Telegram** обо всех ключевых событиях (выдача, продление, ошибки, отключение лота-продления по таймеру)

### Сообщения покупателю
- Полностью настраиваемые шаблоны сообщений (выдача, код, окончание аренды, предупреждения)
- 🆕 **Список доступных команд в сообщении с данными аккаунта** *(1.2.0)* — переменная `$commands_list` автоматически подставляется в шаблон
- 🆕 **Переработанная обработка команд покупателя** *(1.2.0)* — единая точка обработки `!код`, `!статус`, `!продлить` и др., включая выбор варианта продления по времени

### Надёжность
- Атомарная запись всех данных на диск (защита от порчи файлов при сбое/гонке)
- Watchdog и авто-перезапуск фонового воркера обработки заказов
- Диагностика при старте плагина

## 📦 Установка

1. Скопируйте файл плагина (`asrplus_v1_2_0_.py`) в папку `plugins/` вашего Cardinal
2. Перезапустите Cardinal
3. Настройте плагин через Telegram-бота командой `/asrplus`

## ⚙️ Требования

- Cardinal (FunPay)
- Python 3.10+
- Зависимости устанавливаются автоматически при первом запуске

**Рекомендуемые системные требования:** 2 vCPU, 1–2 ГБ RAM, SSD 5–10 ГБ, Linux (Ubuntu/Debian).
